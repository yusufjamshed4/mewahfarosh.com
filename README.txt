MEWAH FAROSH WEBSITE

Files:
- index.html = public customer website
- admin.html = separate admin prototype

HOW TO USE:
1. Upload BOTH files to the root of your GitHub Pages repository.
2. Open index.html for the customer store.
3. Open admin.html for the admin prototype.

IMPORTANT:
The admin prototype uses browser localStorage. It is NOT real secure authentication and product changes are only stored in that browser. For a real online store where products added by you appear for every customer, connect Supabase (database + storage + authentication) before production.

The logo is embedded inside index.html, so no separate image file is required.
